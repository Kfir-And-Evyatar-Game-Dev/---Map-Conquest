# כיבוש המפה | MAP CONQUEST

**לא מספיק לכבוש שטח — צריך גם לשמור על הקשר אליו.**

## על המשחק

**כיבוש המפה** הוא משחק אסטרטגיה בזמן אמת, בהשראת משחקים כמו *Red Alert*. השחקן מתחיל עם בסיס קטן וצבא מצומצם, כובש אזורים על המפה, צובר משאבים ומייצר יחידות כדי להתקדם אל בסיס היריב.

**הטוויסט המרכזי:** כל שטח שבשליטת השחקן חייב להיות מחובר לבסיס דרך רצף של שטחים ידידותיים. אם היריב כובש אזור מרכזי וחותך את הרצף, השטחים המנותקים מפסיקים להניב משאבים והיחידות שנמצאות בהם עלולות להיחלש. אפשר להשתמש באספקת חירום מוגבלת כדי להרוויח זמן ולהחזיר את השליטה.

## איך משחקים?

1. מתחילים עם בסיס וכמה יחידות על מפה דו־ממדית.
2. שולחים יחידות חי"ר ורכבי סיור להשתלט על אזורים ניטרליים או על שטחים של היריב.
3. מקבלים משאבים מהאזורים שמחוברים לבסיס ומייצרים יחידות חדשות.
4. מגנים על מעברים אסטרטגיים, מנתקים את קווי האספקה של היריב ומנסים לשקם אזורים שנותקו.
5. מנצחים כששולטים לפחות ב־70% מהאזורים במשך 20 שניות רצופות, או כאשר משמידים את בסיס היריב.

## פרטי המשחק

- **סוג:** אסטרטגיה בזמן אמת, כיבוש שטחים וניהול משאבים
- **מספר שחקנים:** שחקן אחד מול יריב ממוחשב
- **פלטפורמה מתוכננת:** מחשב אישי
- **תצוגה:** דו־ממד, מבט מלמעלה
- **שליטה:** מקלדת ועכבר
- **מצב הפרויקט:** תכנון במסגרת מטלה 1ב בקורס פיתוח משחקי מחשב
